# GÜNEŞ POLİKARBON Landing Page

A premium, mobile-first sales landing page for polycarbonate products, designed as a static, high-converting marketing page for WhatsApp lead generation.

## Project structure

- `index.html` — page structure and semantic markup
- `css/style.css` — design system, layouts, responsiveness, and interactions
- `js/script.js` — language switching, WhatsApp link generation, sticky header, mobile menu, and reveal animations

## Local preview

Open `index.html` directly in a browser, or run a local static server:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000

## Notes

- Default language is Turkish.
- English and Arabic versions are supported with RTL handling for Arabic.
- All major CTAs open WhatsApp with pre-filled product or general inquiry messages.
- The page is built using plain HTML, CSS, and JavaScript for fast static deployment.
